Raw console output of the three bench runs behind
docs/tuning/2026-07-29-camera-layer-decay.md.

A standalone Nav2 costmap carrying only the camera layer, robot held still at
the origin, fed a 0.1 m patch of points at (0.6, 0.0, 0.10) m for 6 s and then
left alone. "lethal cells" counts cells >= 99 within 0.1 m of the obstacle.
Each run used a random ROS_DOMAIN_ID with ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST.

== 3. STVL with clear_after_reading left at its default (False) ===============

Identical to run 1 apart from that one setting. This is why the comment on it in
nav2_params.yaml shouts: the buffer's newest cloud is re-marked on every costmap
update, which restamps the voxels and restarts the decay, so the layer is as
permanent as the one it replaced -- with no error anywhere.
